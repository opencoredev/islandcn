title: "Agent skill"
description: "An optional install helper for coding agents: the islandcn skill sets up the engine and wires an activity to your app."
---

If you build with a coding agent (Claude Code, Codex, Cursor), the islandcn skill helps it install the engine and wire an activity to your app's real state. It is a folder of Markdown the agent reads; you don't need it to use islandcn.

```package-install
npx shadcn@latest add {{registry}}/islandcn-skill.json
```

It installs `island-core` if the project lacks it and writes the skill to `.agents/skills/islandcn/` and `.claude/skills/islandcn/`. Agents can also read it without installing it, at [/.well-known/agent-skills/islandcn/SKILL.md]({{site}}/.well-known/agent-skills/islandcn/SKILL.md) (index: [/.well-known/agent-skills/index.json]({{site}}/.well-known/agent-skills/index.json)).
